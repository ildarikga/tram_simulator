# 3D-модели прототипа

`kazan-center.glb` — объёмные контуры зданий центра Казани, вода, зелёные зоны, основные дороги и трамвайные пути. Геометрия из OpenStreetMap через OpenFreeMap / OpenMapTiles. Это упрощённая географическая модель с плоским рельефом и условными фасадами. Система координат локальная: X — восток, Y — вверх, Z — юг, единицы — метры. Центр: 49.12° E, 55.79° N. Географическая модель и производная база распространяются с атрибуцией и на условиях, указанных в [лицензии данных](../data/LICENSE.md).

`tram-retro.glb`, `tram-classic.glb`, `tram-long.glb`, `tram-compact.glb`, `tram-yellow.glb`, `tram-blue.glb` — процедурные игровые заготовки, созданные в этом проекте, без сторонних ассетов. Это не точные копии конкретных заводских вагонов. Они экспортируются из текущей сцены и могут иметь смещение начала координат; встроенный импорт центрирует модель автоматически.

Для повторного экспорта при запущенном `npm run dev`: `node scripts/export-models.mjs`. Нужен установленный Google Chrome.
