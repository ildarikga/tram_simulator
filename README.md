# Казань · Трамвайный симулятор

Браузерный 3D-прототип на Three.js. Интерфейс на русском языке.

## Запуск

Нужен Node.js 22.12+ или 24+.

```powershell
npm install
npm run dev
```

Открой http://localhost:5173. Для сборки: `npm run build`. Для браузерных проверок: `npm test` (установленный Google Chrome).

### Доступ из локальной сети

`npm run dev` принимает подключения на всех сетевых интерфейсах, порт `5173`. Пока сервер работает, на другом устройстве в той же локальной сети открой `http://<IPv4 компьютера>:5173` (например, `http://192.168.11.23:5173`). На самом компьютере по-прежнему доступен http://localhost:5173.

IPv4 можно посмотреть командой `ipconfig`: используй адрес активного Ethernet/Wi-Fi адаптера с основным шлюзом. После переподключения к сети адрес может измениться. Если порт занят, сервер сообщит об ошибке вместо перехода на другой порт.

Если Windows блокирует входящие подключения, разреши Node.js доступ в брандмауэре для частных сетей. Либо в PowerShell от имени администратора добавь правило только для устройств локальной подсети (сеть должна иметь профиль «Частная»):

```powershell
New-NetFirewallRule -DisplayName "Tram Simulator LAN (5173)" -Direction Inbound -Action Allow -Protocol TCP -LocalPort 5173 -Profile Private -RemoteAddress LocalSubnet
```

Если домашняя сеть имеет профиль «Общедоступная», можно вместо этого разрешить доступ только с её конкретной IPv4-подсети. Пример для текущего Ethernet-адреса `192.168.11.23` и маски `255.255.255.0` (PowerShell от имени администратора; при изменении сети обнови адреса и имя адаптера):

```powershell
New-NetFirewallRule -Name "TramSimulator-LAN-5173" -DisplayName "Tram Simulator LAN (5173)" -Direction Inbound -Action Allow -Protocol TCP -LocalPort 5173 -LocalAddress 192.168.11.23 -RemoteAddress 192.168.11.0/24 -InterfaceAlias "Ethernet" -Profile Any -Program (Get-Command node).Source
```

Удалить это правило: `Remove-NetFirewallRule -Name "TramSimulator-LAN-5173"` (от имени администратора).

Для просмотра готовой сборки: `npm run build`, затем `npm run preview`; адрес — `http://<IPv4 компьютера>:4173` (для него при необходимости разреши TCP-порт `4173`). Оба сервера работают, пока запущен соответствующий процесс. Устройства должны иметь возможность соединяться друг с другом: гостевой Wi-Fi с изоляцией клиентов может запрещать такой доступ.

Готовые GLB-файлы находятся в `public/models/`: [центр Казани](public/models/kazan-center.glb), [ретро](public/models/tram-retro.glb), [двухдверный](public/models/tram-classic.glb), [длинный](public/models/tram-long.glb), [компактный](public/models/tram-compact.glb), [жёлтый](public/models/tram-yellow.glb), [синий](public/models/tram-blue.glb). Их можно открыть в Blender или другом редакторе glTF. Вагоны — процедурные заготовки, город — географическая модель по данным OSM.

## Публикация на GitHub Pages

Репозиторий: https://github.com/ildarikga/tram_simulator. После первого успешного деплоя сайт будет доступен по адресу https://ildarikga.github.io/tram_simulator/.

В настройках репозитория открой **Settings → Pages → Build and deployment → Source** и выбери **GitHub Actions**. Workflow [.github/workflows/deploy-pages.yml](.github/workflows/deploy-pages.yml) устанавливает зависимости через `npm ci`, собирает сайт на Node.js 24 и публикует `dist/` при пуше в `master` или `main`. Его также можно запустить вручную из вкладки **Actions**. Для деплоя используется встроенный `GITHUB_TOKEN`; SSH-ключ нужен только для отправки локальных коммитов в репозиторий.

Проверка такой же сборки локально:

```powershell
npm run build:pages
npm run preview -- --base=/tram_simulator/
```

Открой http://localhost:4173/tram_simulator/. Команда `build:pages` задаёт базовый путь `/tram_simulator/`, который используется также при загрузке локальной карты. При переименовании репозитория обнови этот путь в `package.json`. Обычные `npm run dev` и `npm run build` используют корень `/`.

На GitHub Pages работает готовый статический сайт: держать свой компьютер включённым не требуется. Свои маршруты по-прежнему сохраняются только в браузере через localStorage; локальные сохранения с localhost автоматически на новый адрес не переносятся. Условия доступности Pages для публичных и приватных репозиториев описаны в [документации GitHub](https://docs.github.com/en/pages/getting-started-with-github-pages).

## Что работает

- Шесть процедурных 3D-вагонов: ретро, обычный двухдверный, трёхсекционный, компактный четырёхдверный, длинный жёлтый и новый синий.
- Настоящая географическая основа Казани: объёмные контуры зданий по всей области карты, улицы, вода и зелёные зоны центра, трамвайная сеть в пределах 48.95–49.31° E и 55.69–55.92° N.
- Выбор номеров 1, 2, 3, 4, 5, 5А, 6, 7, 8. Геометрия движения строится по трамвайной сети между опорными остановками. **Это предварительные трассы номеров, а не проверенная копия официальных маршрутов.**
- Свой маршрут: последовательный выбор опорных остановок, поиск пути по рельсовому графу, сохранение в браузере.
- Разгон, тормоз, ограничение скорости 60 км/ч, двери только после остановки, звонок, пауза, завершение рейса.
- На остановках ждут пассажиры. Остановись центром вагона напротив павильона (в пределах 5 метров) с платформой справа и открой двери (E). После полного открытия пассажиры выходят через двери. Ожидающие начинают заходить, как только соответствующий дверной проём освободится, пока выходящие продолжают идти к павильону. Дождись окончания обмена перед закрытием дверей. Пауза останавливает пассажиров; сброс поездки, смена маршрута или вагона восстанавливают их. Это условная игровая модель без назначения поездок. У импортированных GLB без разметки дверей обмен недоступен.
- Обзорная камера, камера за вагоном и вид вперёд. Дневное и вечернее освещение.
- Именованные остановки OSM: посадочные площадки, павильоны со стеклянными стенками, скамейки, указатели и таблички. На общей карте подписываются остановки выбранной трассы; близко к вагону видны и соседние остановки. В карточке маршрута на карте доступен полный список остановок рядом с его линией.
- Правая сторона определяется по ходу движения вагона. Двустворчатые двери плавно разъезжаются вдоль борта и открывают настоящий проём.
- Выбранный маршрут показан контрастной линией постоянной толщины в пикселях; обзорная камера автоматически охватывает всю трассу.
- Интенсивный фоновый дорожный трафик: 6000 транспортных средств — седаны, хэтчбеки, кроссоверы случайных цветов, автобусы и грузовики. Транспорт движется по улицам карты с правосторонним движением и учётом доступных односторонних участков; пауза останавливает трафик.
- Машины уступают трамваям по их габаритам и ближайшему участку пути, включая нерегулируемые пересечения. Машина, уже находящаяся на рельсах, продолжает движение и освобождает путь; трамвай автоматически ждёт перед её габаритом. Правило действует и для встречных трамваев. Павильоны и светофоры размещаются вне габарита соседних путей.
- Если трамвай и мешающая ему машина неподвижны 5 секунд игрового времени, трамвай временно игнорирует машины, пока не проедет участок блокировки целиком. Затем обычные правила восстанавливаются. Красный и жёлтый сигналы светофора остаются обязательными. Пауза не увеличивает время ожидания; заданная тяга, ручной тормоз и открытые двери по-прежнему определяют движение вагона.
- Выход из блокировки учитывает остановку перед стоп-линией, даже если машина находится дальше по пути. В этом режиме неподвижные мешающие машины не удерживают зелёную фазу трамвая закрытой; остальные участники перекрёстка и обычный цикл светофора продолжают учитываться.
- Встречные трамваи шести типов едут навстречу по выбранной трассе, соблюдают светофоры и дистанцию. Количество зависит от длины маршрута, до 24 вагонов; у конечной они вновь появляются с другого конца трассы. При смене маршрута встречный поток пересоздаётся, на паузе замирает. Соседний путь условно смещён на 4 метра относительно выбранной линии; отдельная проверка фактических встречных рельсов и расписание не моделируются.
- Светофоры на дорожных узлах и пересечениях дорог с трамвайными путями: противоположные подходы работают вместе, поперечные — в другой фазе. Зелёный длится 24 секунды, жёлтый — 3, затем не менее 3 секунд все направления закрыты. Машины и трамвай тормозят перед красным и жёлтым; въехавшие завершают манёвр, поперечный зелёный ждёт освобождения перекрёстка. Машины выстраиваются в очередь. Трамвай сохраняет заданную тягу и автоматически продолжает разгон на зелёный; двери и ручной тормоз сохраняют приоритет. Пауза останавливает также часы светофоров.
- Импорт автономного `.glb` для вагона и города; экспорт текущих заготовок в `.glb`.

Клавиши: W / ↑ — увеличить тягу; S / ↓ — тормоз; E — двери; H — звонок; пробел — пауза. Есть экранные органы управления.

## Точность карты и моделей

Включён локальный снимок OpenStreetMap через OpenFreeMap / OpenMapTiles, загруженный 6 ноября 2026 года. Интернет для работы самой карты не нужен. Контуры реальны, но высоты взяты из `render_height` (при отсутствии — условные), фасады упрощены, рельеф плоский. Объёмные контуры зданий загружены по всей области 48.95–49.31° E, 55.69–55.92° N с буфером тайлов. Каждый поставляемый полигон слоя building строится объёмным; вода и зелёные зоны подробно представлены в центре. Наличие и детализация контуров зависят от исходных векторных тайлов. Это **не полная фотореалистичная 3D-модель всей Казани**.

Трамваи созданы программно в этом проекте. Они **не являются скачанными точными моделями заводских вагонов**. Внешняя модель автоматически масштабируется и центрируется; для сцены города потребуется вручную согласовать её координаты с путями. Поддерживаются автономные GLB с упакованными текстурами, без внешних файлов и без Draco/KTX2-сжатия. У длинного вагона пока нет независимого поворота секций; кабина и салон детально не смоделированы.

Дорожный трафик и светофоры — игровые заготовки. Перекрёстки определяются по геометрии карты, размещение и циклы светофоров условные и не воспроизводят реальные настройки Казани. Нет физики столкновений, отдельных поворотных фаз, уступания встречным при повороте и остановок автобусов. На тупиковых участках машины разворачиваются; на обрезанных границей карты односторонних дорогах появляются на другом участке. Туннели и пешеходные дорожки исключены. Нет расписания и автоматического обслуживания остановок. Вагон следует по линии и останавливается в её конце. Граф путей упрощён из векторных тайлов: соединяются совпадающие участки и малые зазоры, направление и режимы стрелок не моделируются. Свои линии можно строить между десятью опорными остановками; рисование новых рельсов пока не реализовано.

## Актуальные прототипы вагонов

Проверено 5 ноября 2026 года:

- **71-911 City Star**: изготовитель подтверждает поставку в Казань и выход на маршруты 5 и 5А. Это односекционный низкопольный вагон. [ПК Транспортные системы](https://pk-ts.org/sobytiya1/v-kazani-sostoyalas-prezentaciya-tramvaev-city-star-proizvodstva-pk-transportnye-sistemy/).
- **71-711 «Лекат»**: официальный оператор сообщил о выходе нового жёлтого низкопольного вагона на испытания на маршрут 7 21 августа 2026 года. Испытания не означают подтверждённую массовую закупку. [Метроэлектротранс](https://kazanmetro.ru/2026/08/21/ильсур-раисович-метшин-осмотрел-новы/).
- В учебной программе оператора перечислены **71-407, 71-409, АКСМ-62103, АКСМ-84300М, АКСМ-84500К, 71-623-02.02**. Это полезные референсы для последующего создания точного парка, но учебная программа сама по себе не подтверждает количество исправных вагонов на текущую дату. [Программа оператора](https://kazanmetro.ru/wp-content/uploads/2026/02/Образовательная-программа-Tm.pdf).

Цвет и число дверей недостаточны для уверенного определения модели. Синий вагон оставлен авторским вариантом без неподтверждённого заводского обозначения. Следующий этап — выбрать фотографии конкретных вагонов, проверить права на внешние 3D-ассеты и заменить процедурные заготовки точными GLB.

Базовая схема направлений сверялась с [транспортным порталом Казани](https://kazantransport.ru/electric_transport/tram/). Официальные последовательности остановок и варианты движения ещё требуют отдельной сверки.
